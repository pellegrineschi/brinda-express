# Bitácora de desarrollo

Este documento registra cronológicamente las tareas realizadas, los conceptos aprendidos, las pruebas efectuadas y los avances del proyecto Brinda Express.

## 7 de agosto de 2026 — Creación del proyecto

### Tareas realizadas

* Verificación de las versiones instaladas de Node.js y npm.
* Creación de la carpeta general de proyectos.
* Generación del proyecto `brinda-express` mediante Vite.
* Selección de React con JavaScript como tecnología principal.
* Incorporación de ESLint para revisar la calidad del código.
* Instalación de las dependencias con npm.
* Inicio del servidor de desarrollo.
* Comprobación de la aplicación inicial en el navegador.

### Conceptos aprendidos

* Diferencias generales entre React y Angular.
* Función de React como biblioteca para construir interfaces mediante componentes.
* Función de Vite como herramienta para crear y ejecutar el proyecto.
* Función de npm como administrador de paquetes.
* Funcionamiento de `localhost` y de los puertos.
* Actualización automática de la aplicación mediante HMR.

### Resultado

El proyecto React quedó creado y funcionando correctamente en el entorno local.

## 9 de agosto de 2026 — Configuración de Git y documentación

### Tareas realizadas

* Reinicio del servidor de desarrollo mediante `npm run dev`.
* Apertura del proyecto en Visual Studio Code.
* Inicialización del repositorio local con Git.
* Configuración de `main` como rama principal.
* Reemplazo del README inicial de Vite por la documentación de Brinda Express.
* Creación de la bitácora de desarrollo.

### Conceptos aprendidos

* Diferencia entre el proyecto y el servidor de desarrollo.
* Uso de `npm run dev`.
* Función de un repositorio local.
* Diferencia entre archivos sin seguimiento y archivos ignorados.
* Uso básico de Markdown para documentar un proyecto.

### Resultado

El proyecto quedó preparado para registrar sus avances mediante documentación y commits.
